변기즈 공식 홈페이지
====================

구성
- index.html : GitHub Pages용 단일 페이지 홈페이지
- assets/ : 제공된 변기즈 일러스트 5장

포함 기능
- 웹툰 코미디 스타일의 반응형 디자인
- 코디악, 김옥달, 김생명 프로필 및 한 줄 평
- 제공된 단체 일러스트와 장면 갤러리
- 배경 음악 재생/정지 버튼

배경 음악 추가
1. assets 폴더에 bgm.mp3 파일을 넣어주세요.
2. 홈페이지의 음악 버튼을 눌러 재생/정지할 수 있습니다.
3. 브라우저 정책상 음악은 사용자가 버튼을 눌렀을 때 재생됩니다.

GitHub Pages 배포
1. 저장소 최상위 폴더에 index.html과 assets 폴더를 업로드합니다.
2. GitHub 저장소 Settings > Pages로 이동합니다.
3. 배포 소스를 main 브랜치 / (root)로 지정하고 저장합니다.
4. 생성된 Pages 주소에서 홈페이지를 확인합니다.

주의
- Google Fonts 사용 시 인터넷 연결이 필요합니다.
- 배경 음악은 별도 파일이므로 저작권 및 사용 권한을 확인한 뒤 추가하세요.
